# Dr. Colmenares | Archivos

Sitio web de la consultoría en gestión documental, archivos, conservación preventiva y transparencia del Dr. Luis Eduardo Colmenares Gómez.

- Publicado con GitHub Pages: https://colmenaresmx.github.io
- HTML y CSS estáticos, sin dependencias.
- Para conectar un dominio propio: crear el archivo `CNAME` con el dominio y configurar los registros DNS del registrador.
